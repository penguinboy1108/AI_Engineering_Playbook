## Changed

### OpenAI Agents SDK snapshot

The repository's previous point-in-time snapshot referenced `0.19.0`. The latest official GitHub release is now **v0.21.0**, published 2026-08-15.

The durable recommendation does not change: the SDK remains pre-1.0 and version upgrades are behaviour-bearing changes that need explicit version pinning and regression testing.

The current release strengthens the practical testing guidance because it adds provider-neutral deterministic testing utilities for Agent, Sandbox, Realtime and Voice workflows, while also changing or hardening interruption snapshots, recursive approvals, MCP lifecycle state, retry backoff, sandbox path grants and sensitive-error redaction.

Production impact: use deterministic SDK test utilities to improve repeatability where appropriate, but keep provider-backed integration and end-to-end tests because deterministic harnesses do not validate provider behaviour, network paths, model quality, latency or cost.

### Azure AI Inference lifecycle ambiguity retained

Current Microsoft Foundry Models endpoint documentation states that the Azure AI Inference beta SDK retires on **2026-08-26**, while a separate classic migration page still mentions **2026-05-30** for the `azure-ai-inference` package.

This remains an unresolved scope discrepancy rather than a reason to guess. The deprecation registry now makes the distinction more explicit and requires project-level verification of the exact package, endpoint and migration surface.
