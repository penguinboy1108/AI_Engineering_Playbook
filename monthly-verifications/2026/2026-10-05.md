## Promotion candidate: behavioural boundary tests

Security configuration should be tested as behaviour, not assumed from configuration presence. For consequential boundaries, test an allowed path and a denied path and confirm the intended policy decision in telemetry. Where practical, independently verify whether the protected destination observed the request.

Microsoft Foundry's hosted-agent network-egress control is useful only as a reference architecture here. It is currently Preview, has no SLA, and Microsoft states it is not intended for production use.

Source:
- https://learn.microsoft.com/azure/foundry/agents/how-to/add-hosted-agent-guardrails
