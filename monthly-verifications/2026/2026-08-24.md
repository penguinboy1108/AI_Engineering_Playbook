## Changed

### OpenAI Agents SDK advanced to v0.22.0

**[Official release policy and release notes]**

The previous open monthly PR captured `v0.21.0`. The latest official release is now **`v0.22.0`**, published **2026-08-19**.

The durable recommendation remains unchanged: the SDK is pre-1.0 and minor releases can carry breaking public-interface or behaviour changes, so production dependencies should be pinned and upgraded behind regression evidence.

The new release adds concrete migration/test surfaces:

- terminal function-tool output rejected by output guardrails is redacted from replayable and persisted SDK state;
- non-streaming Responses ending in `failed` or `incomplete` status raise `ModelBehaviorError`;
- `OpenAIProvider` rejects conflicting provider options when an explicit client is supplied;
- applications combining explicit `openai_client` with `organization` or `project` must move those values to the `AsyncOpenAI` client;
- usage accounting is isolated between independent `RunState` checkpoints while nested-agent aggregation is preserved.

Production impact: add provider-construction tests, failure/persistence-redaction tests and checkpoint-isolation coverage when upgrading. Retain the `v0.21.0` HTTPX2/OpenAI Python v3 migration checks for applications with custom HTTP clients.
