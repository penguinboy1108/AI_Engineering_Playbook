No new SDK behaviour claim was added in this pass.

## Lifecycle change requiring repository correction

### August 26 Microsoft retirement dates have passed

**[Official lifecycle notices + explicit uncertainty]**

Two registry entries previously described their retirement dates as imminent:

- Azure OpenAI Assistants API (classic): documented retirement date **2026-08-26**.
- Azure AI Inference beta SDK for the current Microsoft Foundry Models endpoint surface: documented retirement date **2026-08-26**.

As of this verification, both dates have passed. However, the current Microsoft pages still use future-tense wording such as "will be retired on August 26, 2026" and do not clearly state the post-retirement request/package behaviour.

The repository therefore does **not** guess that the surfaces are technically unavailable. `DEPRECATIONS.md` now records:

- the documented lifecycle date has passed;
- current operational/support status requires project-level validation;
- continued endpoint response or package installation must not be treated as evidence of support;
- migration remains immediate work for any remaining dependency.

This distinction prevents stale pre-retirement wording from being retrieved as if the deadline were still in the future while also avoiding an unsupported claim about runtime shutdown.

## Other Microsoft lifecycle items revalidated

- Microsoft Foundry Workflows visual experience: **Preview**, retirement announced for **2026-12-01**; Microsoft directs new workflow development to Microsoft Agent Framework.
- Microsoft Foundry Agents (classic): retirement announced for **2027-03-31**; use the generally available current Foundry Agents Service for new implementations.
- Prompt Flow in Microsoft Foundry and Azure Machine Learning: retirement announced for **2027-04-20**; not recommended for new development, and Prompt Flow runtime images no longer receive package or security updates.

## Preview versus GA verification

Current Microsoft Foundry availability guidance continues to require feature-level checks rather than assuming platform-level GA applies to every capability. In particular, Workflows remains Preview and retirement-announced. Existing repository guidance to verify each feature independently remains valid.

## Unresolved uncertainty

### Azure AI Inference lifecycle scope

Microsoft documentation still exposes different lifecycle dates for related legacy inference surfaces: the current Foundry Models endpoint page states **2026-08-26** for the named Azure AI Inference beta SDK surface, while classic migration guidance has referenced **2026-05-30** for the `azure-ai-inference` package. Both dates are now in the past.

Do not collapse these into a single lifecycle claim. Verify the exact SDK package, API surface and endpoint used by each workload.

### Post-retirement behaviour

The current Microsoft pages have not yet been refreshed with an explicit post-retirement state for the two August 26 items. The repository marks this as unresolved rather than inferring either continued support or guaranteed technical shutdown.
