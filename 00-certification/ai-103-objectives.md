# AI-103 Objective Map

## Current official baseline

**[Official exam blueprint]**

The current Microsoft study guide is titled **Exam AI-103: Developing AI Apps and Agents on Azure** and states that the skills measured are effective **April 16, 2026**.

| Domain | Weight |
|---|---:|
| Plan and manage an Azure AI solution | 25–30% |
| Implement generative AI and agentic solutions | 30–35% |
| Implement computer vision solutions | 10–15% |
| Implement text analysis solutions | 10–15% |
| Implement information extraction solutions | 10–15% |

## Production-relevant objective clusters

The current objectives include:

- selecting Foundry services, models, retrieval, memory, tools and knowledge integrations;
- infrastructure, deployment, CI/CD, quota, scaling, rate limits, cost, monitoring and security;
- managed identity, private networking, keyless credentials and role policies;
- safety filters, guardrails, evaluations, trace logging, provenance, approvals and tool-access controls;
- RAG, structured multistep workflows, agents, tool integration, memory and multi-agent orchestration;
- observability through tracing, token analytics, safety signals and latency breakdowns;
- multimodal understanding, generation, content safety, search, OCR, Content Understanding and structured extraction.

## Evidence mapping rules

For each objective, retain three distinct kinds of evidence:

1. **Official knowledge** — current Microsoft documentation and learning material.
2. **Hands-on evidence** — a lab, prototype or production implementation.
3. **Decision evidence** — an ADR, evaluation, incident lesson or trade-off analysis.

This page is a certification index, not a substitute for current product documentation. An exam objective does not prove that a capability is generally available. Verify every service, SDK and feature independently against current lifecycle and availability documentation.
