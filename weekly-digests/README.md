# Weekly Digests

Store one time-stamped digest per research cycle:

```text
weekly-digests/YYYY/YYYY-MM-DD.md
```

A digest is a research record, not automatically a permanent recommendation. Durable guidance should be promoted into the relevant lifecycle page only when the evidence is strong enough.

Each digest must classify findings as added, changed, superseded, deprecated, needs validation, or no action. Use `templates/weekly-digest.md`.
